## 🚀 El proyecto estrella

**TrackAI** no es un reproductor ni un "plugin más". Es un **sistema de inteligencia musical** que vive dentro de tu mezcla:

| 🧠 | ¿Qué hace? |
|---|---|
| **Base de datos vectoriales** | Cada canción se modela por su firma armónica (Camelot), BPM, energía y género. Las sugerencias se calculan sobre un espacio vectorial, no con reglas sueltas. |
| **Motor armónico Camelot** | Transiciones que suenan naturales: misma llave, escalas vecinas, saltos de energía calculados. |
| **Live Pitch®** | El pulso real de la fiesta. Detecta el BPM con el pitch aplicado, grafica la tendencia del set y adapta las zonas de mezcla a tu estilo. |
| **Cerebro que aprende** | Memoria de transiciones personal + global. Cada mezcla que haces entrena un modelo de hábitos: decay temporal, cold start y score con confianza. |
| **Creador de algoritmos** | Motor de recomendación multicapa (continuidad, cambio de ritmo, ultra IA) con score por fases y filtro por crates. |
| **Inteligencia de canciones** | Detecta play count, frescura, carpetas y compatibilidad de BPM/tono sobre `master.sqlite` en vivo, con asentamiento de 7 segundos para evitar falsos positivos. |

## ⚙️ Detalle técnico real

- **Stack:** Electron 31 · Vanilla JS · PostgreSQL (Neon) · SQLite · Cloudflare Workers
- **Motor:** lectura en vivo de `master.sqlite` de Serato cada 3s, sin API pública
- **Licenciamiento:** tokens Ed25519 firmados con verificación criptográfica, activación por key + device, ping de revalidación en vivo (LITE → PRO automático)
- **Seguridad:** rate limiting, comparación timing-safe, anti-replay en webhooks
- **Multiplataforma:** macOS (arm64) + Windows 10/11, un solo código base
- **Monetización:** plan LITE gratuito con publicidad controlada + PRO Fundador
